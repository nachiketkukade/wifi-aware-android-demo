# NAN (Neighbor Awareness Networking) Library

This directory contains the NAN protocol implementation for Wi-Fi Aware functionality.

## Purpose

The NAN library provides protocol-level support for Wi-Fi Aware (NAN) operations, including:
- Device discovery
- Service publishing and subscription
- Data path establishment
- Message exchange

## Structure

This library will contain:
- Protocol handlers
- Message builders and parsers
- Connection management
- Utility classes for NAN operations

## Usage

The NAN library will be used by the Wi-Fi Aware fragment and other components that require NAN protocol functionality.
